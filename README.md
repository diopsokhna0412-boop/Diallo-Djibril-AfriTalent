# AfriTalent

Projet fil rouge — Plateforme de mise en relation entre freelances africains et
clients.

## AUTEUR :

Djibril Diallo

## Promotion :

L1 Web — ISI

## Description :

AfriTalent est une plateforme web fictive de mise en relation entre freelances africains et entreprises à la recherche de talents dans les domaines du développement web, du design, du marketing digital, de la data et de l'intelligence artificielle.

## Technologies utilisées:

HTML5
CSS3
JavaScript (ES6)
Bootstrap 5
Git & GitHub
GitHub Pages

## Fonctionnalités réalisées :

# Interface utilisateur :

Navigation responsive
Mode sombre (Dark Mode)
Bouton "Retour en haut"
Design responsive sur mobile, tablette et ordinateur

# Page d'accueil :

Section Hero
Statistiques animées
Présentation des services
Témoignages clients

# Page Freelances :

Catalogue des freelances
Filtrage dynamique par catégorie
Cartes de présentation

# Page Tarifs :

Plans tarifaires
FAQ interactive (Accordion Bootstrap)

# Page À propos :

Présentation de l'entreprise
Équipe
Valeurs
Compteurs animés

# Page Blog :

Articles à la une
Articles récents
Newsletter

# Page Contact :

Formulaire de contact
Validation JavaScript
Vérification du format email
Messages d'erreur personnalisés
Message de succès

# Animations :

Apparition des sections au scroll (fade-in)
Compteurs animés avec IntersectionObserver
